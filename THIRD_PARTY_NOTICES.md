# Third-party notices

Each task vendors a small set of files from a public repository, byte-identical to the base commit of the pull request. They keep their original licence. The full licence text sits next to the files at `tasks/<task-id>/upstream/`.

Template for each task (to be filled in per task):

## <task-id>

- Repository: <owner/name>
- Licence: <SPDX id>
- Base SHA: <40 hex>
- Pull request: <url>
- Licence text: `tasks/<task-id>/upstream/<LICENSE file>`
